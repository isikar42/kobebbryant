Pricing FAQ

How does the results guarantee work?

Before the pilot starts, we agree on which task the agent takes over and how we measure the time it takes today. At the end of the pilot we measure again. If the agent did not save time, you don't pay for the pilot.

What does annual billing give me?

With annual billing for the Agent plan you pay for 10 months and get 12.

How is Fleet priced?

Fleet is for several agents. Every extra agent gets a discount on the Agent price.
