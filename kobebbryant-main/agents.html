Agents

Each agent takes over one kind of repetitive work, and hands over to a person when it should.

What is an AI agent?

A chatbot gives one answer and stops. An agent gets a goal and works toward it on its own. It repeats a fixed loop: it thinks about the next step, uses a tool, looks at the result, and decides whether it is done.

  1. 1

    Goal

    The user gives a task.

  2. 2

    Think

    The model plans the next step.

  3. 3

    Act

    The model calls a tool, such as search, a calculator or an API.

  4. 4

    Observe

    The tool's result goes back to the model.

  5. 5

    Done?

    No: back to step 2. Yes: the model gives an answer.

Model (LLM)

The "brain". It understands language, makes a plan and picks the right tool.

Tools

Functions the agent is allowed to call. Each tool has a name, a description and parameters.

Memory

What the agent keeps: the conversation history, notes or a knowledge base (RAG).

Guardrails

A maximum number of steps, asking permission for risky actions, and logging.

      Glossary

      LLM
      Large Language Model. A model that predicts text, such as Claude.
      Tool use / function calling
      Besides text, the model can return a structured request to call a function. Your code runs that function.
      ReAct
      Reason + Act. A pattern where the model alternates between reasoning and taking actions.
      RAG
      Retrieval-Augmented Generation. First fetch relevant documents, then give them to the model.
      MCP
      Model Context Protocol. An open standard for connecting tools and data sources to agents.
      Multi-agent
      Several agents with their own roles working together, for example a planner and an executor.
      Evals
      Tests that measure whether an agent does its tasks correctly and reliably.
      Prompt injection
      Outside text, such as a web page, that tries to make the agent do something its creator did not intend.
