FAQ

How does the results guarantee work?

Before the pilot starts, we agree on which task the agent takes over and how we measure the time it takes today. At the end of the pilot we measure again. If the agent did not save time, you don't pay for the pilot.

What happens in the free Agent Fit Scan?

We talk for 45–60 minutes about your processes and where time goes. Afterwards you get a short report: which processes suit an agent, an estimate of the time saved, and an honest opinion if an agent is not worth it.

What is the founding customer offer?

The first 10 customers get their pilot for free. In return we ask for a testimonial and a case study about the pilot.

Which agent fits my business?

That is what the free Fit Scan is for. We look at where your team spends time and tell you which agent fits, if any.
